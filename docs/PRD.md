# PRD — Product Requirements Document

## 제품 개요

**TubeKeep** — YouTube 오프라인 라이브러리 macOS 앱.
PullTube / Downie 스타일의 다운로더를 단순하고 가벼운 메뉴바 형태로 구현.
yt-dlp를 백엔드 엔진으로 사용, SwiftUI + TCA 아키텍처.

---

## 타겟 사용자

- macOS 사용자
- YouTube에서 영상을 자주 다운로드하는 사람
- Downie, 4K Video Downloader 등의 유료 앱 대신 가벼운 무료 대안을 찾는 사람

---

## 핵심 기능 (구현 완료)

### 1. 메뉴바 앱
- Dock 아이콘 없이 메뉴바에서만 동작 (LSUIElement = true)
- SF Symbol `arrow.down.circle` 아이콘 + 2줄 텍스트 (88px 폭)
- 0.3초 간격으로 상태 갱신
- 다운로드 중: 라인1 속도 / 라인2 `완료수/전체수 ETA`
- 완료만 있음: 라인1 `다운로드` / 라인2 `완료 완료수/전체수`
- idle: 라인1 `다운로드` / 라인2 `대기중`
- 다크모드 자동 대응
- 우클릭 메뉴: 라이브러리 / ─ / 영상다운로더 / 일괄다운로더 / 채널다운로더 / ─ / 인터넷속도측정 / ─ / 종료

### 2. 라이브러리 대시보드 (메인 창)
- **좌측 사이드바**: 검색 + 필터 (전체 / 최근) + 채널 목록
  - **전체**: 모든 다운로드 영상
  - **최근**: 48시간 이내 다운로드한 영상
- 앱 실행 시 자동으로 열리는 메인 창 (840×640, 가로폭 고정)
- 좌우 분할 레이아웃 (HStack)
- **좌측 사이드바 (200px)**: 검색창 + 전체/최근 필터 + 채널 목록 (아바타 + 채널명 + 개수)
  - 검색: 실시간 필터링
  - 전체(N) / 최근(N): filterMode 전환
  - 채널 목록: 아바타(디스크+메모리 캐시) + 채널명 + 항목 개수, 우클릭 → 채널로 가기 / 채널 다운로더 열기
- **우측 영역**: 그리드/목록 전환 가능 (툴바 버튼, 기본 그리드)
  - **그리드 모드**: LazyVGrid adaptive min 180px, 16:9 썸네일
    - 좌클릭 → NSMenu (열기 / Finder에서 보기 / 삭제)
    - 인피니트 스크롤 (50개씩)
    - 빈 상태 셀: 그리드 아래 full-width 안내문 + [영상다운][일괄다운][채널다운]
  - **목록 모드**: LazyVStack, 48×27 썸네일 + 제목 + 채널명 + 날짜
    - 동일한 좌클릭 NSMenu
  - 정렬: 최신순/오래된순/제목순/채널순 (정렬 픽커 우측에 뷰모드 토글)
  - 전체 빈 상태: full-screen 안내 + 3개 다운로더 버튼
- **툴바**: [영상다운] [일괄다운] [채널다운] | pin | xmark.circle
- 데이터: UserDefaults JSON ("downloadLibrary"), AppReducer.downloadCompleted 시 저장

### 3. 영상 다운로더 창
- URL 입력 필드 + 정보 조회 + 다운로드 큐 + 설정까지 통합
- 520px 고정 너비, 480px 초기 높이 (zoom 비활성화)
- 툴바: pin + close

### 4. URL 입력 및 정보 조회
- URL 직접 입력 + 클립보드 감시 (2초 간격 Timer)
- **클립보드 감시**: 라이브러리 창이 닫혀 있을 때만 NSPanel 팝오버 표시
  - 라이브러리 창이 열려 있을 때는 다운로더 창을 열고 자동 조회
- Drag & Drop URL 지원
- 자동 URL 감지 (YouTube 전용)
- 조회 중 실시간 로그 표시 (접이식)
- 취소 가능 / 120초 타임아웃

### 5. 영상 정보 표시
- 썸네일(80×45) + 제목 + 채널 + 길이 + 날짜
- 해상도 선택 Picker (모든 가용 포맷, 용량 표시)
- 자막 포함 / 오디오만 추출 옵션
- 기본 해상도 설정 가능 (설정에서 144p~4K, 기본 480p)

### 6. 다운로드 큐
- 목록: 썸네일 + 제목 + 포맷 + 상태(진행률/대기/완료/실패)
- 진행 중 행 배경: 파란색 반투명 채움 (진행률 WaveProgress)
- 상태: 대기 중 → 다운로드 중 → 완료 / 실패
- 전체 시작 / 종료 버튼
- FIFO + 동시 다운로드 수 제한 (1~5)
- 완료 더블클릭 → Finder
- 각 행 우클릭 메뉴: 일시정지/재개/재시도/삭제/Finder열기
- ETA + 통합 속도 표시
- 토스트 알림 (완료/실패/재시도, 3초 auto-dismiss)

### 7. 설정
- 동시 다운로드 수 (1~5)
- 다운로드 속도 제한
- 저장 폴더 선택
- 완료 알림음
- 기본 해상도 (144p ~ 4K)
- 파일명 템플릿
- 클립보드 감시 on/off
- 자동 재시도 횟수
- 최상위 고정 (Pin)

### 8. 글로벌 단축키
- `⌥⌘D` — 라이브러리 창 열기

### 9. 에러 핸들링 및 자동 재시도
- 최대 N회 자동 재시도 (기본 3회, 3초 간격)
- `retrying` 상태 아이콘 + 재시도 횟수 텍스트
- 토스트 알림
- 에러 메시지 인라인 표시 + 툴팁

### 10. 재생목록
- 플레이리스트 URL 감지 시 모달 시트
- 개별 선택/전체 선택 후 일괄 다운로드

### 11. DEBUG 모드
- 조회 테스트 / Mock 테스트 / 상태바 Mock 테스트

### 12. 일괄 다운로더
- 전용 창 (480×420, zoom 비활성화)
- URL 줄바꿈 입력 → 프리셋 일괄 적용
- 백그라운드 순차 정보 조회
- idle → processing → completed 3단계
- 다운로드 큐에 추가 후 5초 카운트다운 → 자동 창 닫힘

### 12.5. 채널 업데이트 알림
- 구독 채널 새 영상을 30분 주기로 자동 감지
- `fetchAllVideos()`로 채널 전체 영상 조회 → `downloadedIDs` + `seenVideoIds`에 없는 ID = 새 영상
- 새 영상 ID를 `UserDefaults("channelsNewVideos")`에 채널별 저장
- 상태바 뱃지: 새 영상 있는 채널 개수 표시 (자동 리셋 안 됨, 클릭 시까지 유지)
- 뱃지 클릭 → 채널 다운로더 창 열기 (첫 새 영상 채널 자동 선택)
- 시스템 알림: UNUserNotification ("채널명: N개")
- 체크 진행률: 상태바 `"업데이트 확인 중 (N/M)"` 표시
- `channelsSeenVideoIds`: 사용자가 확인한 영상 ID 저장 (채널 선택/새로고침 시 newIds→seenIds 이동)
  - 다운로드 안 해도 재감지되지 않음 (확인 완료로 간주)
  - 실제 다운로드 시 seenIds에서 제거
- 채널 리스트: 빨간 ● 배지 (아바타 우상단)
- 채널 선택 시 해당 채널의 newIds→seenIds 이동
- 채널 헤더: 최신 업로드 날짜 + "새 영상 N개 — 새로고침 필요" 오렌지 배너

### 12.6. 디스크 사용량 표시
- 라이브러리 사이드바 하단에 디스크 사용량 표시
- `outputDirectory` + 캐시 디렉토리 용량 합산 (ByteCountFormatter)
- 갱신 시점: 앱 실행 시, 다운로드 완료 시, 항목 삭제 시, 수동 ↻ 버튼
- Finder 바로가기 버튼과 함께 표시: `[폴더] Finder에서 보기  12.3 GB  ↻`

### 13. 채널 다운로더
- 전용 창 (720×520, 세로만 리사이즈 가능)
- 좌우 split: 채널 목록(220px) + 콘텐츠
- 채널 추가/삭제/드래그 재정렬
- 전체 영상 flat-playlist 로딩 → 검색/정렬/인피니트스크롤
- **영상 필터링**: 숏츠 제외 (`@handle/videos` URL 사용), 회원전용 제외 (JSON `availability != "subscriber_only"`)
- 다운로드 완료/대기 영상 체크박스 비활성화 + 회색 처리
- 프리셋: 해상도 / 자막 / MP3
- 24시간 비디오 캐시
- 파일 저장: `{출력폴더}/{채널명}/{index} - {title}.mp4`
- 동영상 개수: 서버 fetch 성공 시에만 업데이트 (필터링된 목록 개수)

### 13. 디버그 로그 (DEBUG 전용)
- 각 window 하단에 동작 로그 패널 (자동 스크롤, 텍스트 복사 가능)
- 창 생성/재사용/포커스 등 주요 이벤트 기록

### 빌드 환경
- SPM (`swift-tools-version: 5.9`)
- `bash build_and_run.sh debug` (또는 release)
- Apple Silicon Mac에서 ARM64-only 바이너리로 빌드
- Intel Mac 지원은 Apple Silicon 호스트에서 `swift build --arch arm64 --arch x86_64`로 유니버셜 빌드 필요 (Xcode.app 필요)
- 모든 리소스(yt-dlp, ffmpeg)는 앱 번들 `Contents/Resources`에 포함

### 앱 번들 포함 항목
| 구성 요소 | 출처 | 역할 |
|-----------|------|------|
| TubeKeep 바이너리 | SPM 빌드 | 메인 앱 |
| yt-dlp | pip 설치 또는 standalone 바이너리 | YouTube 다운로드 엔진 |
| ffmpeg | evermeet.cx static build | 미디어 병합/변환 |
| AppIcon.icns | 프로젝트 | 앱 아이콘 |

### 배포
- 설치: `~/Applications/TubeKeep.app` (build_and_run.sh 자동 설치)
- 배포 방식: 직접 빌드 (Sparkle 등의 자동 업데이트 미구현)
