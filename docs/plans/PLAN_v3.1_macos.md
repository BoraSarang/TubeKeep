# PLAN v3.1 — 유틸리티 기능 확장 (macOS)

**버전**: v3.1.0 · **작성일**: 2026-08-06 · **상태**: 진행 중

## 1. 개요

v3.0 릴리즈 후 사용자 요청으로 선정한 5개 기능을 구현한다.
클립 저장(플레이어 A-B 연동), 채널 자동 다운로드, 전역 단축키, 유휴 시 자막 자동 다운로드, 디스크 정리 뷰.

## 2. 결정 사항

| 항목 | 결정 |
|------|------|
| 클립 저장 위치 | 다운로드 폴더 하위 `TubeKeep/Clips/<videoId>/` + DB(`ClipItem`) 관리 |
| 클립 표시 | 사이드바 신규 카테고리 "클립" (그리드 목록, mpv 재생) |
| 클립 삭제 정책 | 원본 영상 삭제 시 "클립도 삭제할까요?" 다이얼로그 (기본: 클립도 삭제) |
| 채널 자동 다운로드 v1 | 채널별 "자동 다운로드" 토글 → 업데이트 확인 시 신규 영상 자동 다운로드 (예약은 v2) |
| 단축키 | 다운로더 3종 전역 단축키 + 설정 시스템 탭에서 커스텀 (Carbon HotKey) |
| 자막 자동 다운로드 | 유휴 N분(5/10/30) 경과 시 최근 영상부터 자막 없는 것 순차 다운로드, 상태바에 진행 표시, 사용 시 중단 |
| 디스크 정리 | 정렬(용량/날짜/채널) + 필터(미시청 N일/1GB+ 등) + 일괄 삭제 |

## 3. 아키텍처

```
┌─ ClipService ──────────┐   ┌─ ClipStore (DB) ─┐
│ ffmpeg -ss A -to B cut │──▶│ ClipItem 테이블   │
└────────────────────────┘   └──────────────────┘
        ▲ PlayerView "클립 저장" 버튼 (A-B 설정 시)
        │
┌─ AutoSubtitleService ──┐   유휴 타이머(idleTimer) → 최근 영상부터 자막 없으면 yt-dlp --write-subs
└────────────────────────┘   상태바: "자막 다운로드 중: i/N (제목)" / 사용자 액션 시 중단
        │
┌─ ChannelAutoDownload ──┐   채널별 토글 저장(UserDefaults) → 업데이트 확인 시 신규만 enqueue
└────────────────────────┘
        │
┌─ GlobalShortcutService ─┐   Carbon RegisterEventHotKey, 설정에서 커스텀
└─────────────────────────┘
```

## 6. 테스트 계획

- 클립: A~B 설정 → 저장 → 클립 목록 재생/삭제
- 단축키: 설정 커스텀 → 전역 동작
- 자막 자동: 유휴 5분 후 최근 영상부터 자막 없는 것 순차 처리 + 상태바 표시
- 채널 자동: 토글 채널 신규 영상 자동 다운로드
- 디스크 정리: 필터별 목록 + 삭제
- `./build_and_run.sh debug macos --no-launch` ✅ + `swift test` 유지

## 7. 롤백 계획

- 클립: DB `ClipItem` 드롭 + Clips 폴더 삭제, PlayerView 버튼 제거
- 단축키: HotKey 해제, 설정 항목 제거
- 자막 자동: idleTimer 비활성, 설정 토글 기본 off
- 채널 자동: 토글 기본 off
- 디스크 정리: 뷰 제거 (파일 삭제는 사용자 확인 후에만)
