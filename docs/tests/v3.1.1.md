# v3.1.1 테스트 케이스 — 정밀 분석 버그 수정 (T-1050~T-1060)

**빌드**: `bash build_and_run.sh debug macos`
**대상**: TubeKeep.app (v3.1.1, T-1050~T-1060 수정분)
**전제조건**: v3.1.0 동작 확인 완료, YouTube URL 접근 가능, 기존 다운로드/라이브러리 데이터 존재

> 각 TC는 "기대 효과"에 수정 전 문제(버그)와 수정 후 기대 동작을 함께 기록했다.
> 한 번에 순서대로 실행하면 된다.

## TC-31-01: 다운로드 취소 시 성공 오판 방지 (T-1057)

| 항목 | 내용 |
|------|------|
| **기대 효과** | (수정 전) 취소 직후 후처리 로직이 실행돼 "다운로드 성공"으로 잘못 표시될 수 있었음 (수정 후) 취소는 취소로 표시, 부분 파일 삭제 |

**기대 결과:**

- [ ] `.part` 부분 파일이 남지 않음 (임시 파일 삭제)
- [ ] 히스토리에 정상적으로 취소 반영

## TC-31-11: 앱 종료 시 잔여 프로세스 정리 (T-1055, T-1056)

| 항목 | 내용 |
|------|------|
| **기대 효과** | (수정 전) ProcessRegistry lock 내에서 terminationHandler 설정 → deadlock 가능, 파이프 미소비로 yt-dlp/ffmpeg hang (수정 후) 안전한 등록 + stdout/stderr drain |

**절차:**
1. 다운로드 진행 중 앱 종료 (⌘Q)
2. 터미널에서 `pgrep -fl yt-dlp` / `pgrep -fl ffmpeg` 확인

**기대 결과:**
- [ ] 종료 즉시 yt-dlp/ffmpeg 프로세스가 남지 않음
- [ ] 앱 재시작 시 정상 동작 (다운로드 상태 복구 또는 대기 처리)
