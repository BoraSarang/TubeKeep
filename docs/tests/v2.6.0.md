## TC-6-05: 플레이어 창 — 툴바

|------|------|
| **전제조건** | 플레이어 창 열림 |

**절차:**
1. Pin 버튼 클릭
2. Pin 버튼 상태 변화 확인 (pin → pin.fill)
3. 창이 최상위 고정되는지 확인 (다른 창 위에 표시)
4. Pin 버튼 다시 클릭 → 고정 해제
5. Close 버튼 클릭 → 창 닫힘

**기대 결과:**

- [x] Close 버튼으로 창 닫힘
