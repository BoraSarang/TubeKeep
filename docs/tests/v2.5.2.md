## 참고 사항

### Edge TTS (Microsoft)
- 순수 Swift WebSocket 구현 (Python 의존성 없음)
- Microsoft Edge 브라우저의 TTS 서비스 사용
- 한국어 음성: 남성 (ko-KR-InJoonNeural), 여성 (ko-KR-SunHiNeural)
- 인터넷 연결 필요, 오프라인 동작 불가

### 팟캐스트 저장 위치
- 기본: `~/Documents/TubeKeep/Podcasts/{videoId}/`
- 파일: `{videoId}_script.json`, `{videoId}_full.aiff`

### 컨텍스트 메뉴 동작 규칙
| 조건 | 메뉴 항목 | 동작 |
|------|-----------|------|
| 자막 있음 + 팟캐스트 없음 | "AI 팟캐스트 만들기" | 팟캐스트 생성 + 요약 팝업 열기 |
| 자막 있음 + 팟캐스트 있음 | "팟캐스트 재생" | 요약 팝업 열기 (재생 가능) |
| 자막 없음 | "AI 팟캐스트 만들기" (비활성화) | 클릭 불가 |
