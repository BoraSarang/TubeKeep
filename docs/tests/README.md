```

예:
  TC-3-01  (v2.3.0의 첫 번째 테스트)
  TC-4-01  (v2.4.0의 첫 번째 테스트)
```

## 테스트 분류

| 분류 | 설명 | 예시 |
|------|------|------|
| **기능** | 새 기능 동작 검증 | AI 요약, 챕터 생성 |
| **회귀** | 기존 기능 영향 없음 | 다운로드, 라이브러리 |
| **마이그레이션** | 데이터 업그레이드 | SwiftData 전환 |
| **성능** | 속도/메모리 | 응답 시간 |
| **빌드** | 빌드/테스트 통과 | 0 warnings |

## 테스트 진행 규칙

1. **버전 진행 전 확인**: 현재 버전의 모든 테스트 케이스가 통과해야 다음 버전으로 진행 가능
2. **테스트 미완료 시**: 에이전트가 반드시 고지하고 진행 불가
3. **테스트 결과 기록**: 각 테스트 케이스 파일의 결과 요약표에 ✅/⬜ 표시
4. **최종 릴리스**: v2.5.6 테스트 완료 후 release 빌드로 전환
