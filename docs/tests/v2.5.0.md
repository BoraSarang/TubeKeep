## TC-5-01: SQLite DB 생성 및 초기화

| 항목 | 내용 |
|------|------|
| **분류** | 기능 |
| **우선순위** | high |
| **전제조건** | 앱 최초 실행 또는 DB 파일 없음 |
| **의존성** | 없음 |
| **자동화** | 가능 (Terminal 명령어) |
| **예상 시간** | 3분 |

**절차:**
1. 앱 실행
2. Terminal에서 DB 파일 존재 확인:
   ```bash
   ls -la ~/Library/Application\ Support/com.borasarang.tubekeep/tubekeep_ai.db
   ```
3. DB 테이블 구조 확인:
   ```bash
   sqlite3 ~/Library/Application\ Support/com.borasarang.tubekeep/tubekeep_ai.db ".tables"
   sqlite3 ~/Library/Application\ Support/com.borasarang.tubekeep/tubekeep_ai.db ".schema video_ai_data"
   sqlite3 ~/Library/Application\ Support/com.borasarang.tubekeep/tubekeep_ai.db ".schema qna_history"
   ```

**기대 결과:**
- [✅] DB 파일이 정상적으로 생성됨
- [✅] `video_ai_data` 테이블 존재
- [✅] `qna_history` 테이블 존재
- [✅] DEBUG 로그에 `[DB] 데이터베이스 열기 성공` 출력

## TC-5-02: 자막 DB 저장/로드

| 항목 | 내용 |
|------|------|
| **분류** | 기능 |
| **우선순위** | high |
| **전제조건** | 자막이 있는 YouTube 영상 |
| **의존성** | TC-5-01 |
| **자동화** | 불가능 (AI 요약 실행 필요) |
| **예상 시간** | 5분 |

**테스트 URL**: `https://youtu.be/IL8auam0Ujg` (또는 자막 있는 영상)

**절차:**
1. 영상 다운로더에 URL 입력 → 정보 조회
2. "AI 요약" 버튼 클릭
3. 요약 완료 후 DB에서 자막 확인:
   ```bash
   sqlite3 ~/Library/Application\ Support/com.borasarang.tubekeep/tubekeep_ai.db "SELECT video_id, length(transcript), transcript_language FROM video_ai_data;"
   ```

**기대 결과:**
- [✅] 요약 정상 생성
- [✅] DB에 자막 저장됨 (transcript 컬럼에 텍스트)
- [✅] transcript_language가 'en' 또는 'ko'로 저장
- [✅] DEBUG 로그에 `[Subtitle] 자막 DB 저장 완료` 출력
