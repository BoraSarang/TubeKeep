# TubeKeep 수동 테스트 체크리스트

> `./scripts/test-core.sh`로 자동화 테스트를 먼저 실행한 뒤, 아래 항목을 순서대로 수동 확인한다.
> 자동화 스크립트가 통과하지 못하면 수동 테스트를 시작하지 않는다.
> 각 항목 체크 후 `[ ]` → `[x]`로 표시하고 결과를 `docs/tests/results/manual-YYYY-MM-DD.md`에 저장한다.

## 수동 테스트 항목 (자동화 불가)

### A. 다운로드 동작 (네트워크 + 실제 파일)

- [ ] **TC-DL-01 다운로드 완료**: YouTube URL 조회 → 포맷 선택 → 다운로드 → 완료 시 "성공" 표시, 저장 폴더에 파일 존재
- [ ] **TC-DL-02 다운로드 취소**: 긴 영상 다운로드 중 취소 → "취소/실패" 표시, `.part` 임시 파일 없음, 히스토리에 취소 반영
- [ ] **TC-DL-03 일시정지/재개**: 다운로드 중 일시정지 → 진행률 정지 → 재개 → 이어서 완료
- [ ] **TC-DL-04 다운로드 오류**: 존재하지 않는 영상 ID → 한글 에러 메시지, 크래시 없음, 다음 항목 진행
- [ ] **TC-DL-05 중복 방지**: 이미 받은 영상 URL 조회 → "이미 받은 영상입니다" 배지 표시, 큐에 다시 추가 시 "중복된 항목이 제외되었습니다" 토스트
- [ ] **TC-DL-06 큐 드래그 정렬**: 대기 항목 드래그로 순서 변경 → 재시작 후 순서 유지

### B. 플레이어 / 이어보기

- [ ] **TC-PL-01 영상 재생**: 라이브러리에서 영상 재생 → 정상 재생 (mpv)
- [ ] **TC-PL-02 이어보기**: 재생 1분 → 닫기 → 다시 재생 시 해당 위치에서 재개 + 그리드 "이어보기" 배지/진행 바 표시
- [ ] **TC-PL-03 이어보기 제외 규칙**: 5초 미만 시청 또는 마지막 5% 도달 시 재개 안 함
- [ ] **TC-PL-04 클립 저장**: A·B 구간 설정 → 클립 저장 → 사이드바 "클립"에서 재생, 파일명 유니크, 저장 중 UI 프리즈 없음
- [ ] **TC-PL-05 전역 단축키**: 설정에서 단축키 설정 → 앱이 백그라운드일 때 단축키로 다운로더/메인 윈도우 열기

### C. AI 기능 (실제 API 호출)

- [ ] **TC-AI-01 요약 생성**: 영상 요약 요청 → overview/key points 표시, 재요청 시 캐시 히트
- [ ] **TC-AI-02 태그 생성**: 요약에서 태그 분류 → 라이브러리에 태그 저장
- [ ] **TC-AI-03 팟캐스트 생성**: 자막 있는 영상 팟캐스트 생성 → 재생 가능한 오디오 파일
- [ ] **TC-AI-04 QnA**: 요약 기반 질문 → 답변 + 타임스탬프 표시
- [ ] **TC-AI-05 유휴 AI 배치**: 설정→알림→유휴 자막 5분 + "요약·태그 자동 생성" on → 유휴 시 자막 다운로드 후 요약/태그 자동 생성, "팟캐스트 자동 생성" on이면 팟캐스트까지

### D. 채널 / 재생목록 감시

- [ ] **TC-CH-01 채널 추가**: 채널 URL 추가 → 썸네일/영상 목록 로드
- [ ] **TC-CH-02 채널 프리셋**: 채널별 해상도/자막/MP3/일일 한도 설정 → 신규 영상이 해당 옵션으로 자동 다운로드, 일일 한도 초과 시 스킵
- [ ] **TC-CH-03 재생목록 구독**: 재생목록 URL 구독 → 사이드바 하단 표시, 신규 영상 감지 + 자동 다운로드 토글 동작
- [ ] **TC-CH-04 채널 업데이트 알림**: 신규 영상 발견 시 메뉴바 배지 + 알림

### E. 유휴 / 설정 / 마이그레이션

- [ ] **TC-IDLE-01 유휴 자막**: 유휴 자막 5분 설정 → 마우스/키보드 조작 없이 5분 → 자막 없는 최근 영상 순차 다운로드, 활동 시 즉시 중단
- [ ] **TC-SET-01 설정 유지**: 설정 변경 → 앱 재시작 → 값 유지 (리셋 없음)
- [ ] **TC-SET-02 마이그레이션**: 기존 데이터로 앱 실행 → 라이브러리/채널 유지, `[Migration]` 로그 확인
- [ ] **TC-SET-03 알림음/메뉴바 알림**: 다운로드 완료 시 알림음 + 메뉴바 알림 표시, 지속 시간 동작
- [ ] **TC-SET-04 항목 삭제 정리**: 요약 생성한 영상 삭제 → `thumb_<videoId>.jpg` 및 DB AI 데이터/QnA/FTS 잔존 없음
- [ ] **TC-SET-05 잔여 프로세스**: 다운로드 중 앱 종료(⌘Q) → `pgrep -fl yt-dlp`/`ffmpeg` 프로세스 없음, 재시작 정상
