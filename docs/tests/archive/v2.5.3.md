## 참고 사항

### 구현 파일
| 파일 | 설명 |
|------|------|
| `QAModels.swift` | QAResponse, QATimestamp, QAHistoryItem 모델 + `.seekToTime` Notification |
| `QAService.swift` | OpenRouter API 기반 자막 Q&A, 히스토리 CRUD |
| `QAView.swift` | Q&A 시트 UI (질문 입력, 답변 표시, 히스토리) |
| `LibraryReducer.swift` | Q&A 상태/액션 (openQnA, askQuestion, seekToTimestamp 등) |
| `MainView.swift` | 요약 팝업에 "Q&A 하기" 버튼 + Q&A 시트 연결 |
| `DatabaseManager.swift` | qna_history 테이블 CRUD |
| `OpenRouterService.swift` | 공개 `chatCompletion(prompt:apiKey:)` 메서드 |

### Q&A 시트 동작
- AI 요약 팝업 하단 → "Q&A 하기" 버튼 클릭 → Q&A 시트 열림
- 질문 입력 → Enter 또는 전송 버튼 → OpenRouter API 호출 → 답변 표시
- 타임스탬프 클릭 → `.seekToTime` 알림 발송
- 히스토리: SQLite `qna_history` 테이블에 저장, 재로드 가능
- 개별 삭제: 휴지통 아이콘 클릭
