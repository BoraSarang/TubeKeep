## TC-3-01: SponsorBlock

| 항목 | 내용 |
|------|------|
| **분류** | 기능 |
| **우선순위** | high |
| **전제조건** | 시스템 탭 > SponsorBlock 토글 ON (기본값) |
| **의존성** | 없음 |
| **자동화** | 불가능 (수동 재생 확인) |
| **예상 시간** | 5분 |

**절차:**
1. 영상 다운로더에 URL 붙여넣기 → 정보 조회
2. 다운로드 실행
3. 완료된 파일을 플레이어로 재생

**기대 결과:**
- [⬜] 다운로드 로그에 `--sponsorblock-remove all` 확인 (DEBUG 로그)
- [⬜] 완료된 파일 재생 시 스폰서 구간/인트로/아웃트로가 없음
- [⬜] SponsorBlock 토글 OFF 시 원본 그대로 다운로드 (스폰서 포함)

**참고:** SponsorBlock 데이터가 있는 영상 링크 미확보. 추후 재테스트 예정.

## TC-3-02: 메타데이터/섬네일 임베딩

| 항목 | 내용 |
|------|------|
| **분류** | 기능 |
| **우선순위** | high |
| **전제조건** | 시스템 탭 > 메타데이터 임베딩 토글 ON (기본값) |
| **의존성** | 없음 |
| **자동화** | 불가능 (Finder 확인 필요) |
| **예상 시간** | 3분 |

**절차:**
1. 영상 다운로드 완료
2. Finder에서 다운로드된 파일 확인

**기대 결과:**
- [✅] Finder에서 파일 선택 시 미리보기에 제목/업로드 날짜/채널명 표시
- [✅] Quick Look에서 썸네일 확인
- [⬜] `mdls` 명령어로 메타데이터 확인:
  ```bash
  mdls /path/to/file.mp4 | grep -E "kMDItemAuthors|kMDItemTitle|kMDItemContentCreationDate"
  ```
- [⬜] 토글 OFF 시 메타데이터/섬네일 미포함

## TC-3-05: 라이브러리 벌크 액션

| 항목 | 내용 |
|------|------|
| **분류** | 기능 |
| **우선순위** | medium |

**기대 결과:**

- [✅] "열기" 클릭 → 기본 연결 프로그램으로 열림
