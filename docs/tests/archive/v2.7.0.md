## TC-7-01: 시스템 언어 자동 감지

| 항목 | 내용 |
|------|------|
| **전제조건** | 애플 시스템 설정 > 언어 및 지역 > 기본 언어 = 한국어 |

**절차:**
1. 앱 실행
2. 로그 확인 — `LanguageService.systemLanguageCode` 출력 확인

**기대 결과:**
- [x] 시스템 언어가 한국어면 `systemLanguageCode = "ko"`
- [x] 시스템 언어가 영어면 `systemLanguageCode = "en"`
- [x] 자막 다운로드 언어가 시스템 언어 기반으로 설정됨

## TC-7-02: 설정 — 자막 언어 override

## TC-7-05: 프리셋 — 추가/편집/삭제

| 항목 | 내용 |
|------|------|
| **전제조건** | 설정 창 열림, 저장 탭 |

**절차:**
1. 설정 > 저장 탭
2. "프리셋 추가" 버튼 클릭 → 시트 열림
3. 이름 "테스트", 포맷 "영상", 해상도 "720p" 설정
4. "저장" 버튼 클릭 → 프리셋 목록에 "테스트" 추가 확인
5. "테스트"의 "편집" 버튼 클릭 → 시트 열림 → 이름을 "테스트2"로 변경 → "저장"
6. 목록에 "테스트2"로 변경 확인
7. "테스트2"의 "삭제" 버튼 클릭 → 목록에서 제거 확인

**기대 결과:**
- [x] "프리셋 추가" 버튼 → 시트 열림 → 이름/포맷/해상도/자막 설정 가능
- [x] 이름이 비어 있으면 "저장" 버튼 비활성화
- [x] 포맷=오디오 선택 시 해상도 Picker 비활성화
- [x] 저장 시 목록에 즉시 추가
