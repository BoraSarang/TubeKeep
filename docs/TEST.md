# TEST — 테스트 명세서

## v2.3.0 SponsorBlock + 기능 다듬기

---

### TC-01: SponsorBlock

| 항목 | 내용 |
|------|------|
| **전제조건** | 시스템 탭 > SponsorBlock 토글 ON (기본값) |
| **테스트 URL** | 스폰서가 포함된 일반 YouTube 영상 (예: 기술 리뷰 영상) |

**절차:**
1. 영상 다운로더에 URL 붙여넣기 → 정보 조회
2. 다운로드 실행
3. 완료된 파일을 플레이어로 재생

**기대 결과:**
- [⬜] 다운로드 로그에 `--sponsorblock-remove all` 확인 (DEBUG 로그)
- [⬜] 완료된 파일 재생 시 스폰서 구간/인트로/아웃트로가 없음
- [⬜] SponsorBlock 토글 OFF 시 원본 그대로 다운로드 (스폰서 포함)

**스킵 사유:** SponsorBlock 데이터가 있는 영상 링크 미확보. 추후 SponsorBlock 브라우저 확장으로 확인 후 재테스트 예정.

### TC-02: 메타데이터/섬네일 임베딩

| 항목 | 내용 |
|------|------|
| **전제조건** | 시스템 탭 > 메타데이터 임베딩 토글 ON (기본값) |
| **테스트 URL** | 일반 YouTube 영상 |

**절차:**
1. 영상 다운로드 완료
2. Finder에서 다운로드된 파일 확인

**기대 결과:**
- [O] Finder에서 파일 선택 시 미리보기에 제목/업로드 날짜/채널명 표시
- [O] Quick Look에서 썸네일(섬네일) 확인
- [ ] `mdls` 명령어로 메타데이터 확인:
  ```bash
  mdls /path/to/file.mp4 | grep -E "kMDItemAuthors|kMDItemTitle|kMDItemContentCreationDate"
  ```
- [ ] 토글 OFF 시 메타데이터/섬네일 미포함

### TC-03: 다운로드 큐 개별 제어

**절차:**
1. 영상 2개를 큐에 추가 (동시 다운로드 1로 설정)
2. 첫 번째 영상 다운로드 중 상태 관찰

**기대 결과:**
- [O] 다운로드 중인 항목에 ⏸ 일시정지 버튼 표시
- [O] 일시정지 버튼 클릭 → 상태가 "일시정지"로 변경, ⏹ 대신 ▶ 재개 버튼 표시
- [O] 재개 버튼 클릭 → "대기 중" → 슬롯이 비면 자동 재개
- [O] 영상이 실패할 경우 🔄 재시도 버튼 표시

**실패 유발 방법:**
- 네트워크 차단 후 다운로드 시도
- 잘못된 URL 입력 (단, 포맷 선택 이전 단계에서 실패)

### TC-04: 다운로드 실패 시 에러 메시지

**절차:**
1. 유효하지 않은 URL로 다운로드 시도 (예: 비공개 영상 URL)
2. 실패 시 큐 항목 확인

**기대 결과:**
- [O] "실패" 레이블 옆에 간략한 에러 메시지 표시 (60자 제한)
  - 비공개 영상 → "비공개 영상입니다"
  - 403 → "영상에 접근할 수 없습니다 (권한 필요)"
  - 404 → "영상을 찾을 수 없습니다"
- [O] 원본 yt-dlp 에러(stderr) 대신 한글 메시지 표시

**참고:** 회원 전용 영상(UP2eEmO1Kj8) 조회 시 오류 메시지 정상 표시 확인

### TC-05: 라이브러리 벌크 액션

**전제조건:** 라이브러리에 2개 이상의 완료된 영상 존재

**절차:**
1. 라이브러리 열기
2. Cmd+클릭으로 영상 2개 선택
3. 상단 selectionBar 확인

**기대 결과:**
- [O] selectionBar에 다음과 같은 버튼 표시:
  - "Finder에서 보기" (폴더 아이콘)
  - "열기" (재생 아이콘)
  - "선택 해제"
  - "선택 삭제"
- [O] "Finder에서 보기" 클릭 → Finder에서 선택한 파일들이 하이라이트되어 열림
- [O] "열기" 클릭 → 각 파일이 기본 연결 프로그램으로 열림
- [O] "선택 삭제" → 라이브러리에서 제거 + 디스크 사용량 재계산
