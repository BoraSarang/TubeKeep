### 카테고리 리스트
- 드래그 핸들(≡) + SF Symbol 아이콘 + 이름 (카운트 없음)
- drag-drop 순서변경 (FeaturedCategoryDropDelegate)
- 컨텍스트 메뉴: 위로 이동 / 아래로 이동
- @AppStorage("categoryOrder")에 순서 저장

### DiscoverCard hover overlay
- `.overlay()` 3개로 구현 (ZStack 대체, 레이아웃 영향 없음)
  1. `.overlay(alignment: .topTrailing)` — 다운로드 완료 배지
  2. `.overlay { Color.black.opacity(0.35) }` — 어두운 오버레이
  3. `.overlay(alignment: .center) { VStack(버튼) }` — 호버 버튼
- 다운로드 완료: 썸네일 코너 초록 배지 + hover 메뉴 "재생"/"다운로드 완료"(비활성)

## AI 요약 결과 표시 (v2.0.1 통일)

3개 위치에서 동일한 디자인 사용:

| 위치 | 컴포넌트 | 표시 방식 |
|------|---------|-----------|
| Discover/트랜드 | 버튼 → `.popover(arrowEdge: .trailing)` | 팝오버 (버튼 오른쪽) |
| Library/보관함 | 좌클릭 메뉴 "AI 요약" → `.sheet` | 모달 시트 |
| Home/다운로더 | 버튼 → `.popover` | 팝오버 |

### Popover 디자인 (Discover/Home)
```
┌──────────────────────────────┐
│ 📋 AI 요약                [✕]│
│ ──────────────────────────── │
│ 개요: M4 맥북 에어는 40% ... │
│ • M4 칩 40% 성능 향상        │
│ • 15인치 Liquid Retina      │
│ • 18시간 배터리 수명         │
│ • $999부터 시작               │
└──────────────────────────────┘
```
- arrowEdge: .trailing (버튼 오른쪽)
- 닫기 버튼(✕) + popover 자동 dismiss

### Sheet 디자인 (Library 380×320)
```
┌──────────────────────────────────┐
│ 📋 AI 요약                [닫기]  │
│ ───────────────────────────────── │
│ 개요: M4 맥북 에어는 40% ...     │
│ • M4 칩 40% 성능 향상           │
│ ... (ScrollView, 상단 정렬)      │
│                                   │
└──────────────────────────────────┘
```
- 닫기 버튼 (borderedProminent)
- 내용 `.frame(maxHeight: .infinity, alignment: .topLeading)`
- 로딩 시: ProgressView + "AI 요약 중..."
